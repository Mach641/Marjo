Text and buttons remain native HTML. Oooh Baby is a locally hosted handwriting font (Google Fonts, SIL Open Font License in OFL.txt). It approximates the reference lettering; no font file was supplied with the mockups. CTA paper is composed in CSS with the extracted texture and tape. The original mockups contain no third CTA; “Ouvrir le carnet →” is added as explicitly requested, using the same button styling.

All styles are scoped to `opening-active` / `opening-*`. Existing challenge screens and their assets are unchanged.
