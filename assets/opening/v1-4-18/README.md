# Opening assets — V1.4.18

All PNGs are supplied by the user and preserved byte for byte. Assets 02 and 08 are the replacement PNGs supplied separately; the other eight files come from voyage_majorque_opening_assets.zip. No image is generated, redrawn, or extracted from the triptych.

The triptych guides only HTML/CSS composition. Body text, titles and CTA labels remain HTML; the existing local Opening Hand font is reused.

The replacement CTA includes rose tape, used on pages 1 and 3. On page 2, CSS hides that embedded tape and overlays asset 10 in blue. CSS also hides the caption included at the bottom of asset 10. Asset 09 is retained from the supplied pack but is not overlaid on the already-taped replacement button.

The full-screen paper is displayed without tiling; slight overscan hides its supplied outer border. No image masking, recoloring or blending is applied to the rainbow, notebook, heart or botanical illustrations.
